| Write or update | Type | Format |
|---|---|---|
| Product doc | `product` | Purpose / Users / Goals / Non-goals |
| Epic | `epic` | Goal / Scope / Success criteria (measurable) |
| Feature requirements | `feature` (small) or stage `analysis` (large) | Goal, user stories, Acceptance criteria; Problem / Findings / Open questions |
| Sign-off | `signoff: {by, at}` | requested from the human owner; never self-signed |
| Journal | `journal` | decision or correction entries when requirements change |
